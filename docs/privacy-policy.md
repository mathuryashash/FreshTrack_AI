# FreshTrack AI - Privacy Policy

**Effective Date:** April 22, 2026
**Last Updated:** April 22, 2026

## 1. Introduction

FreshTrack AI ("we," "our," or "us") is committed to protecting your privacy. This Privacy Policy explains how our mobile application ("FreshTrack AI") collects, uses, stores, and protects your data when you use our fruit quality assessment service.

We provide an intelligent fruit quality assessment system that uses multi-task deep learning to classify freshness (4 classes), grade quality (3 classes), and predict shelf life from a single image of fruit.

## 2. Data Collection Disclosure

### 2.1 Data We Collect

**Images You Provide:**
- **Fruit Images:** Photographs of fruits that you capture using the app's camera or select from your gallery for analysis
- **Image Metadata:** Timestamp, file format, and basic image properties (resolution, size)

**User-Generated Data:**
- **Predictions:** Freshness classification, quality grade, and shelf-life predictions
- **Feedback:** User-corrected predictions submitted through the feedback feature
- **History:** Local prediction history stored on your device

**Automatically Collected Data:**
- **Device Information:** Device type, operating system version, and unique device identifier (anonymous)
- **Usage Data:** App interaction patterns, feature usage statistics (for improving our service)
- **API Interaction Logs:** Request timestamps, response times, and status codes (for rate limiting and security)

### 2.2 What We DO NOT Collect

- Personal identification information (name, email, phone number)
- Location data
- Contact lists
- SMS or call logs
- Biometric data
- Financial information
- Social media data

### 2.3 Data Collection Method

## 3. Data Usage Statement

### 3.1 How We Use Your Data

**Primary Purpose: Fruit Quality Assessment**

- Process fruit images through our deep learning model (EfficientNet-B0 backbone)
- Generate freshness classification (Fresh, Semi-ripe, Overripe, Rotten)
- Generate quality grading (High/A, Medium/B, Low/C)
- Predict remaining shelf life in days
- Display results in the mobile app

**Secondary Purposes:**

- **Service Improvement:** Analyze aggregate prediction patterns to improve model accuracy
- **Bug Diagnostics:** Use prediction logs to troubleshoot service issues
- **Rate Limiting:** Enforce API usage limits to prevent abuse

### 3.2 Data Processing Locations

- **Image Processing:** Fruit images are processed remotely via our FastAPI backend server
- **Local Storage:** Prediction history is stored locally on your device using SQLite
- **Secure Storage:** API credentials are stored using Android Keystore (encrypted)

### 3.3 AI/ML Disclosure

FreshTrack AI uses machine learning (deep learning with EfficientNet-B0 backbone) to analyze fruit images. The model was trained on a dataset of fruit images with annotations for:
- Freshness classification (4-class)
- Quality grading (3-class)
- Shelf-life estimation (regression)

**Important:** Our system includes Out-of-Distribution (OOD) detection that identifies when an uploaded image does not appear to contain a recognizable fruit. In such cases, the API returns an "OBJECT_NOT_RECOGNIZED" error with an explanation.
